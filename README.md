# پوشه‌یار نقشه‌برداری (Survey Project Manager)

برنامه ویندوزی برای مدیریت پوشه‌ها و فایل‌های پروژه‌های نقشه‌برداری و ثبتی:
فایل‌های اتوکد، اسناد دریافتی، فایل خام توتال / GPS / دوربین و PDF نهایی هر پروژه در یک ساختار ثابت نگه‌داری می‌شوند و فهرست پروژه‌ها در یک فایل اکسل (CSV) ذخیره می‌شود.

> **وضعیت:** نسخه ۰٫۱. برنامه و آزمون‌های آن روی لینوکس (حالت بدون صفحه نمایش) اجرا و بررسی شده است؛ **روی ویندوز واقعی هنوز امتحان نشده**. فایل `.exe` را GitHub Actions روی ویندوز می‌سازد و اگر مشکلی دیدید همین‌جا گزارش بدهید.

## امکانات

- **فهرست پروژه‌ها** با شماره (مثل `1405-014`)، مالک، پلاک، نوع کار، وضعیت و تاریخ تحویل؛ جستجو و فیلتر بر اساس وضعیت.
- **پروژه جدید:** شماره بعدی خودکار با سال شمسی ساخته می‌شود و پوشه پروژه با زیرپوشه‌های ثابت و فایل `README.txt` روی دیسک ایجاد می‌شود.
- **دوبار کلیک روی پروژه:** وارد ریشه پروژه می‌شوید. در کنار، درخت پوشه‌ها و فایل‌ها هست و در وسط، محتوای پوشه انتخاب‌شده (نام، نوع، حجم، تاریخ شمسی).
- دوبار کلیک روی فایل آن را با برنامه پیش‌فرض ویندوز باز می‌کند (DWG با اتوکد، PDF با PDF‌خوان).
- **کشیدن و رها کردن** فایل از Explorer داخل پروژه آن را در پوشه جاری **کپی** می‌کند و هرگز چیزی را رونویسی نمی‌کند.
- پوشه `02_Field_Raw` (فایل‌های خام): فایل‌هایی که اینجا کپی شوند فقط‌خواندنی می‌شوند.
- کپی مسیر، نمایش در Explorer، بایگانی ZIP پروژه، و باز کردن فهرست در اکسل.
- در برنامه هیچ مبلغ یا اطلاعات مالی ذخیره نمی‌شود.

## ساختار پوشه‌ها

```
D:\Projects\                      ← پوشه اصلی (هنگام اولین اجرا انتخاب می‌شود)
├── projects.csv                  ← فهرست پروژه‌ها (در اکسل باز می‌شود)
├── _Archive\                     ← فایل‌های ZIP
└── 1405\
    └── 1405-014_Ahmadi_Karaj\

        ├── 04_CAD                فایل‌های اتوکد
        ├── 05_Final_PDF          خروجی نهایی
```

نام پوشه‌ها لاتین است چون اتوکد و بعضی نرم‌افزارها با مسیر فارسی مشکل پیدا می‌کنند. هنگام ساخت پروژه، نام لاتین از روی نام مالک و شهر پیشنهاد می‌شود و می‌توانید آن را اصلاح کنید.

## اجرا

### فایل آماده (بدون نصب پایتون)
از بخش **Actions** این مخزن، آخرین اجرای موفق را باز کنید و `SurveyProjectManager-windows` را دانلود کنید. در انتشارهای `v*` فایل `.exe` به بخش Releases هم اضافه می‌شود.

### از روی کد
```bat
pip install -r requirements.txt
python run.py
python run.py --root D:\Projects      rem تعیین پوشه اصلی بدون پرسیدن
```

### ساخت .exe روی کامپیوتر خودتان
`build_exe.bat` را اجرا کنید؛ خروجی در `dist\SurveyProjectManager.exe` است.

## آزمون‌ها
```bash
pip install -r requirements-dev.txt
QT_QPA_PLATFORM=offscreen python -m pytest -q tests
```

## تنظیمات
تنظیمات در `%APPDATA%\SurveyProjectManager\config.json` ذخیره می‌شود (پوشه اصلی و سیستم مختصات پیش‌فرضِ نوشته‌شده در README هر پروژه).

## محدودیت‌های نسخه ۰٫۱
- حذف، تغییر نام و انتقال فایل داخل برنامه نیست؛ برای این کارها «نمایش در Explorer» را بزنید.
- اگر `projects.csv` در اکسل باز باشد، ذخیره تغییرات پیام خطا می‌دهد؛ اکسل را ببندید.
- ترجمه نام فارسی به لاتین ساده است و مصوت‌ها را نمی‌نویسد؛ نام پیشنهادی را قبل از ساخت اصلاح کنید.
