# پوشه‌یار نقشه‌برداری (Survey Project Manager)

برنامه ویندوزی برای مدیریت پروژه‌های نقشه‌برداری و ثبتی: پوشه و فایل‌های هر پروژه (اتوکد، اسناد دریافتی، فایل خام توتال و GPS، PDF نهایی)، فهرست پروژه‌ها و متقاضیان، پشتیبان‌گیری و جستجو.

> **وضعیت:** نسخه ۰٫۳. آزمون‌ها و عکس‌های رابط روی لینوکس (بدون صفحه‌نمایش) و آزمون‌ها روی ویندوز GitHub Actions اجرا می‌شوند؛ **استفاده واقعی روی ویندوز (بازشدن اتوکد، کشیدن فایل از Explorer، فونت فارسی) هنوز بررسی نشده**. اگر مشکلی دیدید همین‌جا گزارش بدهید.

## امکانات

**ساختار پروژه**
- شماره پروژه سالانه (`1405-014`) و پوشه هر پروژه زیر پوشه سال: `D:\Projects\1405\1405-014_Ahmadi_Karaj`.
- با ساخت پروژه **فقط پوشه اصلی و `README.txt`** ساخته می‌شود. زیرپوشه‌ها (`01_Documents`، `02_Field_Raw`، `03_Processing`، `04_CAD`، `05_Final_PDF`، `06_Registration`، `07_Photos`، `99_Archive`) هنگام اولین فایلی که به آن‌ها اضافه می‌شود ساخته می‌شوند. در درخت برنامه دسته‌های ساخته‌نشده کم‌رنگ دیده می‌شوند.
- فایل‌های `02_Field_Raw` بعد از کپی فقط‌خواندنی می‌شوند.

**متقاضی و مالک ملک**
- متقاضی (سفارش‌دهنده) و مالک ملک جدا هستند؛ مثلاً یک نماینده برای چند مالک سفارش می‌دهد.
- فهرست متقاضیان (`clients.csv`)، صفحه هر متقاضی با پروژه‌هایش به تفکیک سال و ملک‌هایی که چند بار سفارش داده شده.
- هنگام ساخت پروژه، متقاضی مشابه پیشنهاد می‌شود؛ «ساخت از روی پروژه قبلی» پلاک و مالک را می‌آورد و می‌توانید سند و استعلام را به پروژه جدید کپی کنید. دو پروژه «مرتبط» می‌شوند.

**کار با فایل‌ها**
- **افزودن هوشمند فایل:** فایل را بکشید یا «افزودن فایل» را بزنید؛ برنامه بر اساس پسوند و نام، پوشه مقصد را پیشنهاد می‌دهد (DWG ← `04_CAD`، فایل توتال ← `02_Field_Raw`، عکس ← `07_Photos`، …). مقصد قابل تغییر است، چیزی رونویسی نمی‌شود، و نسخه جدید نقشه (`v04`) نسخه‌های قبلی را به `99_Archive` می‌برد.
- دوبار کلیک روی پروژه آن را در تب جدا باز می‌کند؛ درخت پوشه‌ها، محتوای پوشه و پیش‌نمایش (عکس، صفحه اول PDF، جدول نقاط، متن فایل خام) کنار هم هستند. دوبار کلیک روی فایل آن را با برنامه پیش‌فرض (اتوکد، PDF‌خوان) باز می‌کند.

**فهرست و جستجو**
- صفحه اصلی: پروژه‌های نزدیک به موعد یا عقب‌افتاده، پروژه‌های اخیر، توزیع وضعیت‌ها و وضعیت پشتیبان.
- جستجوی سراسری با `Ctrl+K`: متقاضی، پروژه و نام فایل در همه پروژه‌ها (ارقام فارسی و لاتین یکی حساب می‌شوند).
- `projects.csv` و `clients.csv` کنار پوشه‌ها ذخیره می‌شوند و در اکسل باز می‌شوند. مبلغ یا اطلاعات مالی ذخیره نمی‌شود.

**دیگر امکانات**
- **ورود پوشه‌های موجود:** پروژه‌های قدیمی را بدون جابه‌جا کردن فایل‌ها ثبت کنید (یا در ساختار استاندارد کپی کنید).
- **پشتیبان‌گیری افزایشی:** فقط فایل‌های جدید یا تغییرکرده کپی می‌شوند و چیزی از مقصد پاک نمی‌شود؛ یادآوری دوره‌ای.
- بایگانی ZIP پروژه، تم تیره و روشن، نمایش ارقام فارسی یا لاتین.

## فناوری

**C# و .NET 8** با رابط **Avalonia UI** (راست‌به‌چپ و فارسی)، **PDFium** برای پیش‌نمایش PDF. خروجی یک فایل `.exe` مستقل برای ویندوز است و نصب .NET لازم ندارد.

```
src/SurveyProjectManager.Core   منطق برنامه (تاریخ شمسی، CSV، متقاضی، پوشه‌ها، افزودن فایل، پشتیبان، جستجو)
src/SurveyProjectManager.App    رابط کاربری Avalonia
tests/SurveyProjectManager.Tests آزمون‌ها (xUnit، شامل آزمون رابط بدون صفحه‌نمایش)
```

## اجرا

### فایل آماده
از بخش **Actions** این مخزن، آخرین اجرای موفق را باز کنید و `SurveyProjectManager-windows` را دانلود کنید. در انتشارهای `v*` فایل `.exe` به بخش Releases هم اضافه می‌شود.

### از روی کد
[.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0) را نصب کنید، سپس:
```bat
dotnet run --project src\SurveyProjectManager.App
dotnet run --project src\SurveyProjectManager.App -- --root D:\Projects
```

### ساخت .exe روی کامپیوتر خودتان
`build_exe.bat` را اجرا کنید؛ خروجی در `dist\SurveyProjectManager.exe` است.

## آزمون‌ها
```bash
dotnet test
```
برای گرفتن عکس از صفحه‌ها در آزمون‌های رابط، متغیر محیطی `SPM_SHOT_DIR` را روی یک پوشه بگذارید.

## تنظیمات
در `%APPDATA%\SurveyProjectManager\config.json` ذخیره می‌شود: پوشه اصلی، سیستم مختصات پیش‌فرض (در README هر پروژه نوشته می‌شود)، مقصد پشتیبان، پروژه‌های اخیر، تم و ارقام.

## فایل‌های نسخه قبلی
اگر `projects.csv` نسخه‌های قبلی را دارید، بدون تغییر باز می‌شود: برای هر پروژه یک متقاضی هم‌نام مالک ساخته می‌شود و فایل `clients.csv` اضافه می‌شود.

## محدودیت‌های فعلی
- حذف، تغییر نام و انتقال فایل داخل برنامه نیست؛ از «نمایش در Explorer» استفاده کنید.
- پوشه‌های خالی بعد از پاک کردن فایل‌ها خودکار پاک نمی‌شوند.
- پیش‌نمایش DWG ممکن نیست؛ با اتوکد باز می‌شود.
- اگر `projects.csv` در اکسل باز باشد، ذخیره تغییرات خطا می‌دهد؛ اکسل را ببندید.
- ترجمه نام فارسی به لاتین ساده است و مصوت‌ها را نمی‌نویسد؛ نام پیشنهادی پوشه را قبل از ساخت اصلاح کنید.
- تشخیص «همان ملک» بر اساس متن موقعیت/پلاک است (ارقام فارسی و لاتین یکی حساب می‌شوند).
